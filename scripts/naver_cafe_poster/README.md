# 🤖 Playwright 기반 네이버 카페 자동 포스팅 도구 사용 방법

이 도구는 네이버 카페 스마트에디터 ONE을 기반으로 바이럴 게시글(제목, 본문, 태그)을 자동으로 입력해 주는 반자동화 매크로입니다.

---

## 1. 사전 준비 (최초 1회)

Playwright 라이브러리가 설치되어 있지 않다면 아래 명령어로 설치합니다:

```bash
npm install -D playwright
```

---

## 2. 설정 파일 수정 (`config.json`)

`scripts/naver_cafe_poster/config.json` 파일을 열어 포스팅할 카페 URL과 원고 내용을 수정할 수 있습니다.

* **`targetCafes`**: 포스팅하고자 하는 네이버 카페의 글쓰기 페이지 URL (`writeUrl`) 및 원고 타입 지정
* **`posts`**: 제목, 본문 줄바꿈 배열, 태그 설정

---

## 3. 포스팅 스크립트 실행

프로젝트 루트 디렉토리에서 아래 명령어로 스크립트를 실행합니다:

```bash
node scripts/naver_cafe_poster/poster.mjs
```

---

## 4. 작동 방식 & 사용 흐름

1. 스크립트 실행 시 Chrome 브라우저가 화면에 열립니다.
2. 네이버 로그인 세션이 없으면 **로그인 화면**이 노출됩니다. (최초 1회 수동 로그인 진행)
   * *로그인 정보 및 쿠키는 `./.naver_user_data` 폴더에 지속 저장되어 다음부터는 자동 로그인 상태가 유지됩니다.*
3. 로그인이 완료되면 자동으로 지정한 카페 글쓰기 페이지로 이동합니다.
4. **제목, 본문(줄바꿈 최적화), 태그**가 에디터에 자동으로 타이핑 입력됩니다.
5. 입력이 완료되면 화면에서 최종 내용을 확인하고 **[등록]** 버튼을 눌러 글을 등록합니다.

---

## ⚠️ 주의 사항

* 네이버 캡차(CAPTCHA) 방지를 위해 수동 로그인 세션(`userDataDir`)을 재활용하는 방식입니다.
* 카페별로 **글쓰기 권한(가입 및 등급)**이 사전에 충족되어 있어야 글쓰기 폼이 정상적으로 켜집니다.
